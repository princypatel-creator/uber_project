🚀 **My Power BI Project – Uber Ride Analytics Dashboard**

I'm excited to share my latest Data Analytics project: **Uber Ride Analytics Dashboard**, developed using Microsoft Power BI.

The objective of this project was to analyze Uber ride-booking data and transform raw data into meaningful business insights.

📊 **Key Areas of Analysis:**
- Completed, Incomplete & Cancelled Bookings
- Total Revenue and Ride Distance
- Monthly Booking Trends
- Vehicle Category Performance
- Popular Pickup & Drop Locations
- Customer & Driver Ratings

🛠️ **Tools & Technologies:**
- Microsoft Power BI
- DAX
- Power Query
- SQL
- Microsoft Excel

💡 **What I Learned:**

Through this project, I improved my skills in data cleaning, data analysis, KPI development, DAX measures, and interactive dashboard design.

This project has been a valuable step in my journey towards becoming a Data Analyst.

I'm looking forward to building more projects and continuously improving my analytical skills!
